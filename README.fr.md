# WayFilee

WayFilee est un fork de [Filee](https://github.com/KnifeLemon/Filee) destiné à Fedora/Nobara avec KDE Plasma Wayland. Son interface Avalonia est native et n’utilise pas d’interface web. Consultez le [README anglais](README.md) et les [instructions d’installation](installer/linux/INSTALL.txt) pour l’installation, la compilation et les limites actuelles.
