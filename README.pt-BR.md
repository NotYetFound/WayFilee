# WayFilee

WayFilee é uma versão derivada do [Filee](https://github.com/KnifeLemon/Filee) para Fedora/Nobara com KDE Plasma Wayland. A interface de desktop é nativa, feita com Avalonia, sem interface web. Consulte o [README em inglês](README.md) e as [instruções de instalação](installer/linux/INSTALL.txt) para instalação, compilação e limitações atuais.
