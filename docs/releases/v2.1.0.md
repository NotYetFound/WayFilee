# WayFilee 2.1.0

The first WayFilee release brings Filee's native file converter and donut toolbar to KDE Plasma on Wayland. Fedora/Nobara KDE is the primary tested desktop. Ubuntu, Debian, Arch, and other KDE Wayland distributions are targets but still need clean-system installation and upgrade testing.

## Highlights

- Native Avalonia Wayland UI, with a KWin script that positions the donut at the pointer. X11, Windows, macOS, and other compositors are outside this fork's current target.
- Global mouse gestures through libinput, plus a drop zone and Dolphin context action that work without input-device access.
- Donut fixes for borders, focus dismissal, stray blank windows, and opening speed. Its appear and disappear animations have Instant, Fast, Normal, and Slow presets.
- WayFilee branding and SVG-based icon; Material You (M3) is the default theme for new settings.
- Self-contained x64 and arm64 archives, RPM, DEB, and Arch packages, each with a SHA256 checksum file.

## Install

Choose one asset for your architecture and distribution: `.rpm` for Fedora/Nobara, `.deb` for Ubuntu/Debian, `.pkg.tar.zst` for Arch, or `.tar.gz` for the per-user installer. Do not install both a system package and the per-user archive installer at the same time. See the [README](../../README.md) and [Linux installation notes](../../installer/linux/INSTALL.txt) for commands and KDE setup.

## Updates and current limits

WayFilee checks GitHub Releases. Archive installs can upgrade themselves; system packages download a matching package, verify its SHA256 checksum, then ask the system package manager to install it with administrator authentication. A live update from a published release will be testable only after a newer WayFilee version exists. GitHub-hosted packages do not appear in normal Discover or distro repository update checks.

The x64 RPM has been installed and launched on Nobara KDE. A synthetic RPM upgrade passed a dry run. DEB, Arch, and arm64 packages have not been installed on clean target systems yet. Optional conversion engines are not bundled and can be managed from the **Engines** page.

For a detailed list of visible changes from Filee, see [User-visible changes](../USER_VISIBLE_CHANGES.md).
