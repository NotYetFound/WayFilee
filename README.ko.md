# WayFilee

WayFilee는 Fedora/Nobara의 KDE Plasma Wayland를 위한 [Filee](https://github.com/KnifeLemon/Filee) 포크입니다. Avalonia 기반의 네이티브 데스크톱 앱이며 웹 UI를 사용하지 않습니다. 설치, 빌드 방법과 현재 제한 사항은 [영어 README](README.md)와 [설치 안내](installer/linux/INSTALL.txt)를 참고하세요.
